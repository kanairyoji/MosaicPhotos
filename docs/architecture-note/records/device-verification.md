> **なぜこの一覧があるか**

> 変わったのは「OS の処理枠」「回線ポリシー」「継続タスクの表示」「共有相手とのやり取り」など、

### 解析の公開（ADR-222）

- **1 回の公開の重さ**（ADR-222 追補 4）: `share.publishAnalysis` の開始から終了まで、
  フットプリントが跳ねないこと（以前は 637MB・67 秒）。ログの `PERF TICK footprint=` を見る。
- まず**設定の「今すぐ公開」**で確かめる（窓を待たない）。結果がその場に出る
  （「上げた N シャード・残り M」／「変更なし」／抜けた理由）。
- 家族の端末（または 2 台目）を同じ Dropbox に繋ぎ、夜の窓を 1 回回す。
  `<root>/<端末>/Analysis/.mosaic-share/shard-xx.json` ができ、**2 回目の窓で 0 件**になること
  （毎回全部を上げ直していないこと＝`share.publishAnalysis: 変更なし`）。
- 受け取り側で `share import:` が家族フォルダの**外**の写真にも当たること（タグ・顔・人物名）。
- 設定「写真の解析結果を共有」を OFF にしたら、窓でアップロードが 1 件も出ないこと（既定 OFF）。
- **2 台目で ON にしたとき**: 設定画面に「別の端末がすでに解析結果を共有しています」と
  相手の端末名・最終公開日が出ること。その状態で「今すぐ公開」しても
  `share.publishAnalysis: 別の端末（…）が公開している` で 1 バイトも上がらないこと。
  「この端末で公開する」を押すと公開が始まり、`<root>/.mosaic-analysis-owner.json` の
  `deviceFolder` がこの端末に変わること。
