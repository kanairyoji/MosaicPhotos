## 見るべき診断ログ

Developer Options → 診断ログ。目印になる行:

- `analyze:` — 解析セッションの開始・停止・理由
- `share import: capture dates — +N, total M, overCap X, evicted Y, saveFailed Z`
- `ShareAnalysisFetch: receiver capability 1 → 2`（**1 回だけ**）
- `ShareAnalysisFetch: download failed` / `invalid analysis data`（区別されていること）
- `merged.rebuild: local=… cloud=… total=… sort=…ms`
- `embed: batch` / `embed: skipped — already running`
