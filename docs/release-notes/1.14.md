# App Store リリースノート — v1.14

App Store Connect の「このバージョンの新機能（What's New in This Version）」へ投入する原稿。

- **日本語（`ja`）** … 日本の App Store 向け
- **英語（`en-US`）** … 日本以外（既定言語）向け

> 運用: 日本語版が原文。英語版は訳だが、直訳ではなく英語として自然な言い回しにする。
> App Store の文字数上限は 4,000 文字。機能名は**アプリの実際の表示名**と一致させること。

---

## 日本語（ja）

```
ピープル（人物）が実機できちんと進むようになりました。

■ 修正
・端末によって顔さがしが最初の1枚から進まなくなる不具合を修正しました。写真の解析（人物・タグ・説明文）が夜間に確実に進みます。
・グリッドのサムネイルや人物アイコンが90度横倒しで表示されることがある不具合を修正しました。
・フォルダアルバムが古いままになることがある問題を修正しました。

■ ピープル（人物）
・「確認」を顔さがしの最中でも開けるようにしました。好きなときに数問答えるだけで、認識精度が上がります。
・答え終わったあと、その場で次の候補を探せる「Find more」を追加しました。
・ぼやけた顔や顔でないものを取り込みにくく、別の人が混ざりにくくなりました。

■ 場所
・地名をより正確にしました。小さな町や区・町名まで表示されることがあります（充電中に静かに補正します。圏外でも表示は止まりません）。
・場所アルバムの並び順を「写真の多い順」にしました（同数のときは新しい写真がある場所が先）。

■ Dropbox
・Dropbox の写真にもお気に入り（ハート）を付けられるようになりました。
・お気に入りの写真は解析でも優先され、説明文などが早く付きます。

■ 表示と操作
・全画面表示の操作を画面下部にまとめ、メニューの出し方を統一しました。
・クラウドのアルバムで、撮影日が不明なときに実在しない日付を表示しないようにしました。

■ 動作
・写真を見ている間の重さを減らし、スクロールや画面の切り替えを軽くしました。
・夜間の解析を高速化し、メモリの使用も抑えました。

写真の解析はすべて端末の中だけで行い、外部には送信しません。
```

## English (en-US)

```
People recognition now works reliably on device.

Fixed
• Fixed an issue where face scanning could stall on the very first photo on some devices. Photo analysis (people, tags, descriptions) now makes steady progress overnight.
• Fixed grid thumbnails and person avatars sometimes appearing rotated 90 degrees.
• Fixed folder albums that could remain out of date.

People
• You can now open Review while face scanning is still running. Answering just a few questions whenever you like makes recognition noticeably better.
• Added "Find more" so you can look for the next set of questions without closing the screen.
• Blurry faces and non-faces are far less likely to be picked up, and people are less likely to be mixed together.

Places
• Place names are more accurate. Smaller towns and neighborhood names may now appear. Refinement happens quietly while charging, and names still show when you are offline.
• Place albums are now ordered by photo count, with the most recently photographed place first when counts match.

Dropbox
• You can now mark Dropbox photos as favorites.
• Favorites are analyzed first, so their descriptions appear sooner.

Viewing
• Full-screen controls are grouped at the bottom of the screen, and menus now open consistently.
• Cloud albums no longer show a placeholder date when the capture date is unknown.

Performance
• Reduced work while you are browsing, so scrolling and screen transitions feel lighter.
• Faster overnight analysis with lower memory use.

All photo analysis runs entirely on your device. Nothing is sent anywhere.
```
