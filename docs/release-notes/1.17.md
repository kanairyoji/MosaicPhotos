## 日本語（ja）

```
同じ Dropbox を使う家族のために「解析結果だけを共有」を追加しました。あわせて、夜間の解析が止まりにくくなり、人物認識とクラウド写真の日付も正確になっています。

■ クラウド共有：解析結果だけを共有（新機能）
・家族で同じ Dropbox を使っている場合、写真を 1 枚もコピーせず「解析結果だけ」を共有できるようになりました。同じ写真を端末ごとに何日もかけて解析し直す必要がなくなります。
・設定 → アルバムと検索 → クラウド共有 →「写真の解析結果を共有」をオンにしてください（既定はオフ）。「今すぐ公開」で待たずに出せます。
・受け取る側は何もしなくてよく、共有フォルダの登録も要りません。
・オンにするのは 1 台だけにしてください。別の端末が公開しているときは端末名を表示し、「この端末で公開する」で引き継げます。

■ バックアップとオフロードの安全策
・オフロード済みの写真が Dropbox 上で見つからなくなったときに、自動オフロードを停止してお知らせするようになりました。写真一覧の上に帯が出て、どのファイルが対象かを確認できます。
・Dropbox 側で写真が移動・削除された場合に「ファイルがありません」が残り続ける問題を解消しました。アプリが自分で気づいて一覧から外します。
・Dropbox に入れた新しい写真がいつまでも出てこないことがある問題を解消しました。自動で立ち直ります。

■ クラウド写真の日付
・クラウド写真の撮影日は、写真に埋め込まれた撮影日時だけを使うようにしました。Dropbox へアップロードした日時を撮影日として使うことはなくなり、並び順が正確になります。
・撮影日時は裏で少しずつ調べるので、枚数が多い場合は数日かけて埋まっていきます。

■ ピープル（人物）
・夜のあいだに人物全体を見直して組み直すようになり、同じ人が分かれにくくなりました。
・名前・束ね・ピープルグループの所属は、組み直しや再スキャンでも引き継がれます。
・写りの悪い顔も拾うようにしたので、見つかる人が増えています。一覧が埋まらないよう、自動で出るのは 10 枚以上に写っている人だけです（名前を付けた人は枚数に関係なく出ます。「すべて表示」から最小枚数を変えられます）。
・代表写真の選び方を見直し、その人らしい顔が選ばれやすくなりました。

■ 解析の進み方
・「すべて解析済みです」と表示が出る条件を正しくしました。残りがあるのに完了と出ることがなくなり、残っているときは「まだ解析していない写真があります」と出ます。
・AI 解析の状況で、見つかった人物・検出した顔・検索の索引の残りも確認できるようになりました。
・メモリの使い方を大きく見直し、夜間の処理が途中で止まりにくくなりました。
・起動直後から写真のタグが表示されるようになりました。

■ その他の改善
・大量の写真があるときの一覧表示と起動を高速化しました。
・設定に「充電をバックグラウンド処理より優先」を追加しました（既定オン）。
・人物アルバムの枚数が英語で表示されていた問題を修正しました。
```

## 英語（en-US）

```
Analysis-only sharing arrives for families on one Dropbox account. Nightly analysis is far less likely to stall, and both face grouping and cloud photo dates are more accurate.

■ Cloud Sharing: share the analysis, not the files (new)
• If your family shares one Dropbox account, you can now share only the analysis — no photos are copied. Each device no longer spends days re-analyzing the same library.
• Turn on Settings → Albums & Search → Cloud Sharing → “Share photo analysis” (off by default). Use “Publish now” if you don't want to wait.
• Receiving devices need no setup at all, not even a shared folder.
• Turn it on for one device only. If another device is already publishing, the app shows which one and offers to take over.

■ Backup and offload safeguards
• If a photo you already offloaded can no longer be found in Dropbox, automatic offload now stops and tells you, with a banner above your photos and a list of the affected files.
• Fixed cloud photos that stayed in the grid but failed to open after being moved or deleted in Dropbox. The app now notices and removes them.
• Fixed new Dropbox photos sometimes never appearing. Syncing now recovers on its own.

■ Cloud photo dates
• Cloud photos now use only the capture date embedded in the photo. The Dropbox upload time is never used as a capture date, so ordering is correct.
• Capture dates are looked up gradually in the background, so a large library fills in over a few days.

■ People
• People are now re-grouped as a whole overnight, so the same person splits less often.
• Names, grouped people and people-group membership are carried over through re-grouping and full rescans.
• Lower-quality faces are now included, so more people are found. To keep the carousel readable, only people in 10 or more photos are listed automatically (anyone you have named always appears, and you can change the minimum from Show All).
• Cover photos are chosen more representatively.

■ Analysis progress
• “Everything is analyzed” now appears only when it is true. When work remains you will see “Some photos are not analyzed yet.”
• The AI analysis screen now also shows people found, faces detected and remaining search index items.
• Memory use was reworked substantially, so nightly processing is much less likely to be cut short.
• Photo tags now appear right after launch.

■ Other improvements
• Faster grid rendering and launch with very large libraries.
• New setting: “Prioritize charging over background work” (on by default).
• Fixed photo counts in person albums appearing in English.
```
